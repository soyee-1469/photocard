# 토마톡 포토카드 — GPT 전달용 기획안

2026-10-06. 이 문서가 화면 디자인 기준이다.

GPT에게 부탁하는 일: **모바일 화면 시안**을 그려 달라. 폭 390, 확인 폭 360과 430. 아래 화면 흐름, 문구, 등급, 토큰은 확정이다. 새 화면, 새 등급, 새 카피, 새 구매 단위를 제안하지 마라. 열린 질문은 마지막에만 있고, 그 질문의 답으로 시안을 바꾸지 마라.

서비스는 사내 메신저 토마톡 안의 디지털 포토카드다. 실결제는 없다. 통화는 **TOTT**. 데이터는 테스트 목업이다.

---

## 1. 한 줄

미개봉 포토카드팩을 고르고, 테스트 결제로 산 뒤, 개봉 연출로 랜덤 카드 1장을 받아 내 앨범(바인더)에 넣는다.

경험 비율의 감각은 구매 30, 개봉 30, 수집 40이다. 다만 정보 구조는 쇼핑몰 탭을 유지한다. 비밀 아카이브라는 별도 세계관 사이트로 다시 만들지 마라.

## 2. 확정. 되돌리지 말 것

| 항목 | 확정 |
|---|---|
| 탭 | 홈, 상품, 내 앨범. 3개 |
| 구매 | 1팩 = 랜덤 카드 1장. 수량 선택 없음. 5팩 없음 |
| 통화 | TOTT. 예시 가격 10,000 TOTT, 잔액 52,000 TOTT. 원화 없음 |
| 등급 | N, R, SR, SSR. SECRET 없음 |
| 결제 | 확인 시트에서 테스트 결제. 잔액 부족이면 TOTT 지갑 |
| 개봉 | 결제 직후 전체 화면 연출. SSR 약 6초, N/R/SR 약 3초. 건너뛰기 있음 |
| 저장 | 결과 다음 시트에서 고른다. 기본 앨범, 기존 카테고리, 새 카테고리. 카드 한 장은 한 곳. 기본 앨범은 미분류 |
| 앨범 | 가진 카드만. 미보유 실루엣, `?`, 수집률 `28/120` 없음 |
| 당첨 카드 | 결제 후 개봉 전까지 어떤 장이 뽑혔는지는 보여 주지 않음 |
| 알림함 | 없음. 미개봉 팩은 홈 배너 |
| 화면 폭 | 360–480. 480을 넘으면 가운데 정렬 |
| 언어 | 한국어 |

금지 목록. 이전 시안에 있던 것이라 다시 넣기 쉽다.

- 페이지명 `PACK ARCHIVE`, `MY ARCHIVE`, `READY TO OPEN`, `OPEN CARD` 전용 화면
- 카피 `UNVEIL YOUR STAR`, `FIND YOUR RAREST MOMENT`
- SECRET 등급, 홀로그램 그라디언트, 화면 플래시
- 상품 썸네일을 카드 뒷면만으로 통일. 목록 대표 이미지는 앨범 커버다
- 오픈 전에 아이돌 사진을 전부 가리기. 상세의 라인업과 대표 카드 앞면은 구매 전에 보인다
- 미보유 칸, 물음표, 수집률
- PC 4열, 좌우 펼침 바인더. 바인더는 모바일 한 페이지 2열×2행
- 골드 금속 버튼을 주 버튼으로 쓰기
- 가격, 탭, 링크를 등급색이나 골드로 칠하기

## 4. 화면

공통: 맨 위 테스트 배너 `테스트 모드 · TOTT 테스트 데이터 (실결제 없음)`. 배경 `bg.raised`, 글자 `text.secondary`.

### 4.1 홈

위 → 아래.

1. 헤더. 로고 `토마톡 PHOTOCARD`, 잔액 `52,000 TOTT`, 메뉴
2. 미개봉 팩이 있으면 배너. 예: `개봉하지 않은 팩 1개`
3. 히어로 배너 캐러셀
4. 섹션 `추천`. 상품 카드 가로 스크롤
5. 섹션 `신규`. 같은 카드, 가로 스크롤
6. 아티스트 칩. 탭하면 상품 목록에 그 아티스트 필터
7. 섹션 `내 카드`. 가진 카드 미니 4장. 없으면 섹션을 비우거나 짧은 빈 문구. 잠금 카드로 채우지 말 것

### 4.2 상품 목록

1. 헤더 `상품`, 잔액
2. 검색. 높이 44. 플레이스홀더 `상품, 아티스트, 앨범 검색`
3. 필터 한 줄. `아티스트`, `앨범`, `등급`, `판매중`, 정렬
4. 결과 수와 적용된 필터 칩. 예: `8개 상품 · ARTIST A ✕`
5. 2열 그리드

상품 카드에 넣을 정보만:

- 앨범 커버. 비율 4:5
- 좌상 태그 `NEW` 등. 우상 판매 상태 또는 최고 등급 배지 하나. SSR이 포함되면 `SSR`만
- 아티스트. `text.secondary`
- 앨범명. 한 줄
- `10종 중 랜덤 1장`
- 가격. `10,000 TOTT`. `text.primary`

필터는 시트다. 아티스트 단일 선택, 앨범은 아티스트 선택 후, 등급은 복수(그 등급이 포함된 상품), 판매중은 토글. 정렬은 신규순, 인기순, 가격 낮은순, 가격 높은순.

품절·판매 종료는 이미지 투명도 0.45와 배지. 탭하면 상세로 간다.

물음표 카드, 카드 뒷면 썸네일, 4열은 쓰지 마라.

### 4.3 상품 상세

구매 전에 구성을 확인하고, 뽑힐 장은 숨긴다. 라인업 전체는 보여 준다. 앨범 커버와 대표 카드 앞면은 다른 사진이다.

위 → 아래.

1. 헤더. 뒤로, 더보기. 스크롤 전 투명, 스크롤 후 `bg.base`
2. 히어로 페이저 3장. 앨범 커버 1:1, 대표 카드 앞면, 대표 카드 뒷면. 점 인디케이터. 판매 상태 배지
3. `ARTIST A · ALBUM ONE` (`text.secondary`)
4. 상품명 `ALBUM ONE 포토카드팩` (heading2)
5. 배지 `Photobook Ver.` `테스트용 목업`
6. `10,000 TOTT` 와 `1팩 = 랜덤 1장`
7. 하이라이트 3칸. `55×85mm` / `10종` / `양면`
8. 대표 카드. 앞면·뒷면을 나란히. 탭하면 플립, 드래그하면 약한 틸트. 등급 빛은 그 카드 등급만
9. 구성품
   - 포토카드. `10종 중 랜덤 1종 · 55×85mm · 양면`
   - 카드 뒷면. 공통 1종
   - 보관. 개봉 후 내 앨범에 저장 (위치는 저장 시트에서 선택)
10. 상품 정보 7행
    - 아티스트
    - 앨범·버전
    - 발매일
    - 판매 기간
    - 카드 규격 `55 × 85 mm`
    - 마감 `N 무광 · R 유광 · SR 홀로 · SSR 골드 홀로`
    - 구성 `포토카드 10종 중 랜덤 1장`
11. 카드 라인업. 4열, 55:85, 등급 테두리. 탭하면 그 카드가 대표 카드로 바뀐다. 이게 당첨 카드라는 뜻은 아니다
12. 등급별 획득 확률. 백분율, 종수, 막대, **합계 100%**
    - 예시: SSR 5% 1종, SR 15% 1종, R 30% 3종, N 50% 5종
13. 유의사항 접기. 화면과 실물 색 차이, 랜덤 교환 불가, 디지털 상품, 테스트 데이터
14. 하단 고정. 가격 + `10,000 TOTT 구매하기`

판매 상태별 버튼 문구: 판매중은 구매, 출시 예정은 `D-n`, 품절, 판매 종료.

### 4.4 구매 확인 시트

바텀 시트.

- 상품 요약
- 가격, 현재 잔액, 결제 후 잔액
- 확률 요약 한 줄 4칸. 상세와 같은 숫자. 합계 100%
- `테스트 결제` 문구. 실결제 아님을 다시 보여 줌
- `결제하기` (primary), `취소` (ghost)

### 4.5 팩 개봉

전체 화면. 배경은 `bg.base`. 카드와 연출만 남긴다.

- SSR 약 6초, N/R/SR 약 3초
- 건너뛰기
- 모션을 줄인 설정이면 결과로 바로 이동

등급 연출은 5.4. 길이를 1초 안쪽으로 줄이지 마라.

### 4.6 개봉 결과

- 큰 포토카드. 등장 시 등급 샤인
- 등급 배지, `NEW`
- 카드 이름
- 이어서 저장 시트

`한 장 더 오픈` 버튼을 결과의 주 행동으로 두지 마라. 다시 사려면 상품으로 돌아간다.

### 4.7 저장 시트

- 기본 앨범 (미분류)
- 기존 카테고리 라디오
- 새 카테고리 이름 입력 후 바로 만들기
- `저장` (primary)
- 저장 후 내 앨범. 보조로 `계속 쇼핑`은 상품 목록

### 4.8 내 앨범

- 기본 앨범 + 카테고리 타일. 각 타일에 보유 수
- 최근 획득 4장
- 앨범 열기 → 바인더

카테고리 만들기, 이름 변경, 삭제는 타일의 더보기 시트. 이번 시안의 주인공은 아니다.

### 4.9 바인더

- 필터: 아티스트, 등급
- 한 페이지 **2열 × 2행**. 카드 폭은 (페이지 폭 − 간격) / 2. 한 줄로 늘어지면 실패다
- 페이지 인디케이터. 스와이프로 넘김
- 포켓을 탭하면 카드 상세 오버레이
- 속지 색은 크림 `#F4EBDC`. 커버와 바깥 크롬만 네이비 토큰. 속지를 네이비로 칠하지 마라
- 빈 칸에 `?` 나 검은 실루엣을 넣지 마라. 가진 카드만 포켓에 있다

### 4.10 카드 상세 오버레이

- 닫기. 닫으면 바인더 페이지는 유지
- 큰 카드. 탭 플립, 드래그·호버 틸트, SSR은 샤인
- 등급, 획득일, 보유 수
- 뒷면은 공통 카드 뒷면

### 4.11 TOTT 지갑 / 구매내역

헤더 메뉴에서 진입.

- 잔액 카드. `bg.raised` + `border.default`. 골드 그라데이션 금지
- 거래 리스트

### 4.12 이용 안내

짧은 정적 안내. 테스트 데이터, 디지털 상품, 확률은 상품 상세에 있다는 정도. 새 기능을 만들지 마라.

## 5. 디자인 토큰

UI는 네이비에 가깝게 무채색이다. 채도 있는 색은 등급의 보더, 배지, 글로우, 모션에만 쓴다. 서피스 전체를 등급색으로 물들이지 마라.

### 5.1 색

| 토큰 | 값 | 용도 |
|---|---|---|
| bg.base | `#080812` | 페이지 |
| bg.surface | `#10101A` | 섹션 띠, 탭바 |
| bg.raised | `#151522` | 카드, 입력, 필터, 정보 칸 |
| bg.overlay | `#1C1C2B` | 시트, 메뉴 |
| scrim | `rgba(8,8,18,0.72)` | 시트 뒤 |
| border.subtle | `#1C1C2B` | 1px 구분선 |
| border.default | `#2A2A3A` | 1px 입력, 카드 |
| border.selected | 1.5px `#F7F7FB` | 선택, 포커스 |
| text.primary | `#F7F7FB` | 제목, 본문, 가격, 활성 탭 |
| text.secondary | `#AAAABD` | 보조, 읽어야 하는 캡션 |

| rarity.R | `#6CA7FF` | 배지, 테두리, 글로우 |
| rarity.SR | `#9674FF` | 배지, 테두리, 글로우 |
| rarity.SSR | `#F4C56A` | 배지, 테두리, 글로우, SSR 샤인. 버튼과 가격에 쓰지 않음 |

기능색은 상태 배지와 오류에만.

| 토큰 | 값 |
|---|---|
| success | `#4ADE80` |
| warning | `#FFB547` |
| danger | `#FF6B6B` |
| info | `#6CA7FF` |

판매 배지: 출시 예정은 info, 품절은 secondary 글자 + default 테두리, 판매 종료·공급 종료는 `#2A2A3A` 바탕 + secondary 글자. 품절을 SR 보라로 칠하지 마라.

### 5.2 글자

UI 서체는 Pretendard. 세리프 디스플레이는 쓰지 마라. 360–480에서는 48, 36 디스플레이도 쓰지 마라.

| 토큰 | 크기/행간 | 굵기 | 용도 |
|---|---|---|---|
| heading1 | 28/36 | 800 | 개봉 결과 카드명 |
| heading2 | 22/30 | 700 | 상품명 |
| heading3 | 18/26 | 700 | 섹션, 시트 제목 |
| body1 | 16/24 | 500 | 본문, 버튼 |
| body2 | 14/22 | 500 | 리스트 |
| label | 13/18 | 600 | 칩, 필터 |
| caption | 12/16 | 500 | 메타. 필수면 secondary |
| price | 16 또는 20 | 800 | 가격. 색은 text.primary. 숫자 정렬 |

제목 자간 -0.2. 배지 자간 +0.4. 최소 글자 12.

### 5.3 간격, 모서리, 버튼

간격은 4의 배수. 자주 쓰는 값: 8, 12, 16, 24, 32. 화면 좌우 16. 섹션 간격 32. 카드 안 12. 그리드 간격 12.

| 토큰 | 값 | 용도 |
|---|---|---|
| radius.xs | 4 | |
| radius.sm | 8 | 입력 |
| radius.md | 12 | 상품 카드, 버튼, 포토카드 |
| radius.lg | 16 | 시트 위, 카드 상세의 큰 카드 |
| radius.xl | 24 | |
| radius.pill | 999 | 칩, 배지 |

터치 영역은 44 이상. 칩 높이 36이면 히트 영역을 44로. 주 버튼 높이 52.

버튼:

- primary. 채움 `#F7F7FB`, 글자 `#080812`. 글로우 없음
- secondary. 투명, 테두리 `#2A2A3A`, 글자 `#F7F7FB`
- ghost. 글자 `#AAAABD`. 닫기, 취소, 보조
- danger. 파괴 동작만

`OPEN CARD` 특수 버튼은 없다.

### 5.4 등급 표현

글로우는 호버, 선택, 리빌에만. N에는 없다.

| 등급 | 색 | 연출 |
|---|---|---|
| N | `#B6BAC8` | 짧은 페이드, 약한 샤인. 글로우 없음 |
| R | `#6CA7FF` | 파란 가장자리 글로우 |
| SR | `#9674FF` | 보라 빛 스윕, 중간 파티클 |
| SSR | `#F4C56A` | 골드 버스트, 방사 빛, 샤인 스윕 |

파티클과 스파클은 이미 있는 효과 이미지를 등급에 나눠 쓴다. 새 장식 일러스트를 그리지 마라.

카드 플립 500–650ms. 호버 틸트 약 180ms, 각도는 대략 ±12도 안. UI 전환 120 / 200 / 320ms. 시트 240ms. 결과 카드의 등급 샤인은 약 800ms. 이 샤인과 개봉 영상 6초는 별개다.

반복해서 열어도 피곤하지 않게, 개봉 영상 외에 1초를 넘는 장식 모션을 붙이지 마라.

---

## 6. 컴포넌트 경계

`PhotoCard`와 상품 카드는 다른 컴포넌트다.

포토카드 데이터: 멤버, 등급, 번호, 컬렉션, 즐겨찾기, 보유, 앞면, 뒷면.

상품 카드 데이터: 컬렉션, 팩 이름, 가격, 한정 여부, 종수, 앨범 커버, 판매 상태.

포토카드 크기:

| 자리 | 크기 | 플립 | 틸트 | 샤인 |
|---|---|---|---|---|
| 홈 내 카드, 라인업, 바인더 포켓 | 작음 | 없음 | 없음 | 정적 |
| 상세 대표 카드 | 중간 | 있음 | 있음 | 인터랙션 |
| 카드 상세, 개봉 결과 | 큼 | 있음 | 있음 | SSR은 등장 시 스윕 |

배지 종류만: 등급 N/R/SR/SSR, 판매 상태, 공급 종료, NEW, 개수, 테스트용 목업. 강한 색은 등급 배지만.

## 7. 시안을 낼 때

그려 줄 화면: 홈, 상품 목록, 상품 상세, 구매 시트, 개봉, 개봉 결과, 저장 시트, 내 앨범, 바인더, 카드 상세.

프레임은 390×844. 상태 한 가지씩이면 된다. 빈 앨범, 품절, 잔액 부족은 목록·상세·구매 시트 옆에 작게.

토큰 밖의 색을 추가하지 마라. 카드 위 사진이 주인공이고, 크롬은 조용해야 한다.

확인만 하고 시안에 반영하지 말 것:

- 바인더 속지를 네이비로 바꿀지
- 디지털 상품 상세에서 `55×85mm`와 마감 문구를 뺄지

지금은 둘 다 이 문서대로다. 속지는 크림, 규격과 마감은 보이되 `테스트용 목업` 배지를 붙인다.
